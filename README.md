# Практична робота №8-9

Проєкт створено за відповідною практичною роботою з Word/PDF-документа.

## Що реалізовано

- Окремі `catch` для різних помилок.
- `NotPositiveNumberException`, `NotFractionalNumberException`, `finally`, `Stopwatch`.

## Git

У репозиторій не додаються `bin/`, `obj/`, `.vs/` і `*.user`.
